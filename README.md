# Нооруз CRM — демо

Кликабельное демо CRM для учебного центра: ученики, ежемесячные оплаты, напоминания в WhatsApp, проверка чеков (распознавание — Gemini), сверка с выпиской банка.

Все данные вымышленные и хранятся только в вашем браузере. Сообщения никуда не отправляются.

**Открыть:** https://timqshy.github.io/nooruz-demo/

На телефоне: откройте ссылку и выберите «На экран Домой» — демо установится как приложение (PWA).

## Что попробовать

1. **Входящие** — чеки от родителей с проверкой (сумма, получатель, дата, повторный номер операции), вопросы родителей.
2. **Ученики** — список по статусам. В карточке ученика вкладка «Симуляция»: прислать чек или вопрос от имени родителя.
3. **Следующий день** (внизу слева или дата вверху на телефоне) — бот рассылает напоминания по правилам и выставляет новые начисления.
4. **Сверка с банком** → «Загрузить пример выписки» — чеки, деньги по которым пришли, можно подтвердить одной кнопкой.
5. **Настройки** — когда напоминать, тексты сообщений, реквизиты.

## Разработка

Без сборки: статические файлы, ES-модули. Бизнес-логика — в `logic.js` (без DOM), тесты:

```bash
npm test
```

Локально: `python3 -m http.server` в этой папке.
